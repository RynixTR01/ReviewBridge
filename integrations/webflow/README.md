# Webflow embed install

1. Copy `reviewbridge-embed.html` into an **Embed** element on the target page.
2. Replace `WIDGET_TOKEN` with the 32-character embed token shown in ReviewBridge.
3. Add the site's published host to the widget's allowed domains, publish the page, and verify it in a private browser window.

This is a manual embed, not a Webflow Marketplace application. A native app still needs a Webflow developer account, OAuth/app registration, marketplace review, and live site testing.
